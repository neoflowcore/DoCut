# DoCut V0.17 — 자료 근거형 통계차트 9종 및 안전한 편집 계약

작성 기준 2026-11-04 / **소스 구현 및 자동검증 단계**. 외부 이미지 레퍼런스의 수치, 애니메이션 시간, 로고·상표·색상을 그대로 복사하지 않는다. 스크린샷 89장은 구현을 위한 유형 가이드일 뿐 통계 데이터나 영상 프레임 데이터가 아니다.

## 목표 및 절대 규칙

- 사용자 입력을 주고받는 `stat` 개체(가로세로 이동·크기 조절·타 페이지 복제·레이어 관리 가능)를 보통 막대/선/도넛 개체와 구분한다.
- 표본, 신뢰한계, 예측값, AUC, 관리 상한·하한, 포레스트 플롯의 비교기준선을 **임의로 만들지 않는다**. 없는 값은 빈 안내 상태로 보이고 콘텐츠 점검에서 경고한다.
- 숫자/자료 또는 출처/단위 변경 시 `verified=false`가 되고, 원자료의 부분 적용·자동 생략 없이 오류를 사용자에게 알리고 원본을 보존한다.
- 자료가 없는 통계 차트는 인증 표시를 허용하지 않고, 관리도는 세 가지 한계값 모두 입력하기 전까지 인증을 거부한다. ROC 끝점이 없으면 AUC를 산출하지 않고, 코호트 기간 상승이나 누적 리프트의 종단점 누락은 근거 경고만 제공한다.
- 통계차트 CSV 입력 시 사용자 기존 출처를 덮어쓰지 않고 CSV 파일명을 추가 근거로 보존한다. 기존 일반 차트/표 CSV 출처 동작은 구버전 호환을 위해 유지한다.
- 모든 그래프 도형을 동일한 결정적 `geometry`에서 만들며 SVG(실행 HTML·캔버스)와 PPTX(네이티브 선/사각형/원/텍스트)는 그 지오메트리를 공유한다. PPTX는 Excel 연동형 차트가 아니고 HTML 애니메이션도 옮기지 않는다.
- 복잡한 외부 디자인에 대한 픽셀 단위 일치는 보장하지 않으며 원본 89장을 기준으로 한 측정도 아직 없다.

## 지원 유형 · 원자료 열

| 유형(`kind`) | 형식 · 의미 | 필수 원칙 |
|---|---|---|
| `cohort` | 코호트, 기간(정수 0~48), 잔존율 % | 코호트·기간 중복 거부, 모집단/기간 정의를 근거에 남길 것 |
| `multiples` | 그룹, 기간, 수치 | 최대 4개 그룹, **동일 기간 이름/개수**만 비교 |
| `control` | 시점, 관측값 | 하한·중심선·상한 모두 직접 입력, 순서 검증 |
| `forest` | 항목, 추정치, 하한, 상한 | 하한 ≤ 추정 ≤ 상한, `referenceValue`는 선택 직접 입력(없으면 기준선 없음) |
| `fan` | 기간, 하한, 중앙, 상한 | 구간 순서 검증, 구간 세로표시와 중심값 연결선 |
| `survival` | 시간, 위험집단 수, 사건 수 | 시간순, 사건 수 ≤ 위험집단, 이전 사건에 맞는 감소 조건. 검열·중도탈락은 사용자가 분리 정의할 것 |
| `contribution` | 항목, signed 기여값 | 입력값의 누적합과 연결선만 계산, 수치 자동 대체 없음 |
| `lift` | 누적 인구비율 %, 누적 양성 포착률 % | 0~100 범위 및 단조성 검증. 모집단 정의 필요 |
| `roc` | 위양성률, 진양성률 | 두 값 모두 0~1, 단조성 검증. AUC는 (0,0)→(1,1) 끝점과 실제 값이 있을 때만 사다리꼴로 계산 |

`assets/stat_charts.js`가 `normalize()`, `parseRows()`, `warnings()`, `geometry()`, `svg()`를 소유한다. 최대 48행·12,000자(직접 원자료), 라벨 64자, 300개 SVG 도형 제한을 준수한다. 지원되지 않는 유형, 중복/누락 열, 비유한값, 잘못된 범위는 예외를 발생시키고 **전체 갱신을 거부**한다. 원자료가 없으면 `원자료를 입력하세요`라고 표시한다. 지표가 8개를 넘으면 표시 밀도 경고를 노출한다.

## 편집기 실제 동작

1. 자산→`통계 차트 9종` 추가하면 **빈 코호트 차트**가 생성되고 자동 숫자는 입력되지 않는다.
2. 속성→유형 선택, 원자료(`|` 또는 탭으로 구분) 입력, 기준선/관리 한계 직접 입력, 기존 팔레트 선택. 종류 변경은 원자료/한계/기준선을 비우며 Undo로 복구 가능하다.
3. 통계의 필드명만 `자료 열 제목 복사`로 복사할 수 있다(샘플 숫자 없음). `CSV/TSV 셀 데이터 불러오기`는 기존 파일 검토 창에서 **미적용 → 원자료 비교 → 명시적 승인/취소** 후 적용한다. 검토 중 대상이 바뀌면 적용을 거부한다.
4. 통계차트 전용 `statistic` 프리셋(페이드→도형 순차 공개), 최대 3개 모션과 순서 변경·타임라인·정지/Undo 지원. 하위 도형의 개수를 제한하며 숨긴 탭 및 `prefers-reduced-motion` 상태를 존중한다.
5. 독립 HTML은 원자료와 출처·단위를 JSON으로 복구할 수 있고, **출처 패널의 펼쳐보기 표에서 원자료 모든 행과 검증 경고를 직접 열람**할 수 있다. TXT 요약에는 실제 입력한 모든 행만 포함한다. PPTX는 텍스트·선·도형 편집 가능(실제 Microsoft PowerPoint에서 열기/수정/재저장은 수기 미검증).
6. 마스터 로고, 기존 페이지 스토리, 다른 16개 요소 유형, 테마·레이아웃·모션 값은 그대로 보존한다.

## 앞으로도 남는 한계

표본·검열·신뢰수준·판정 임계값의 **통계학적 적정성 자체**는 사용자가 근거를 확인해야 한다. 팬 차트는 하한/중앙/상한 간격 표시이며 확률밀도/분위수 띠 추정이 아니다. 원본 레퍼런스 영상의 타이밍·가감속은 복원되지 않았다. 기기별 폰트/고해상도 및 PowerPoint 실제 렌더링은 물리 검증을 요청받은 뒤 확인해야 한다.
