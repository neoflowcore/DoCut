## V0.12.0 추가 구현 범위 (기존 60개 기준을 임의 확대하지 않음)

- 브라우저 안에서 cubic-bezier 제어점 2개를 드래그·방향키로 수정, 곡선 6종 프리셋과 시간대별 이징 진행률 미리보기.
- 직접 중간 키프레임 마커의 드래그/키보드 시간 변경, 실행 취소 1회 단위 제어.
- 일반 HTML에서 안전한 내장 `<style>`의 단순 선택자/정적 배치, `:root` 변수, 상속된 서체·색, 테이블 셀 서식과 슬라이드 배경색을 추출. 외부 CSS 및 동적 자바스크립트·Grid/Flex는 변환하지 않음.
- 일반 HTML의 굵게/기울임/밑줄/부분 색상 텍스트를 제한적 서식으로 재구성.
- 가져오기 진단에 실제 인식한 CSS 규칙 개수와 손실 범위를 설명 (일치율 % 표시 안 함).
- 모바일 속성 패널의 가려진 닫기 버튼 결함 수정, Esc 종료 및 터치 접근 확인.
- `npm test` **73/73 PASS**. Chromium 브라우저 11개 스위트가 로컬 수동 병렬 통합 러너에서 **11/11 PASS**. 순차 1개 워커 경로는 제한시간으로 종료된 이전 기록으로 분리. 자동 레이아웃 80장 QA 확인. 실제 사용자 기기 수기검증 미수행.
