# DoCut v0.48 — 숫자 범주열·지표 단위 안전 매핑 (2026-11-11)

## 검증 가능한 수정 범위
- 실제 엑셀 원본에서 Year/Quarter/연도/기간/Region 등 차원(범주) 제목을 숫자열보다 우선하도록 개선. 열 순서가 뒤바뀌어도 지표 수치와 범주를 혼동하지 않게 함.
- 모든 표본 열이 숫자이고 범주 제목이 모호하면 회사 6페이지 자동 매핑 중단. 작성자가 범주 열 번호를 지정한 후 재검토해야 적용할 수 있음.
- 차트별 수동 **값 열** 지정과 별도로 공통 **범주 열** 선택 지원. 데이터 변경·범위 변경 시 검토 결과 무효화.
- 충돌하는 명시 단위(통화·비율·인원) 자동 연결 차단. 무단 단위 환산 없음.
- 한 글자/복수 토큰 의미 일치를 신중히 유지하고, 기존 Bain Investment/Exit 국영문 매핑은 계속 허용.
- 기존 프로젝트, 공식 보고서 템플릿, 16:9 SVG·스타일 및 저장 데이터는 일괄 마이그레이션하지 않음.

## 계측과 미완료 게이트
- 새 소스 모델: 범주열·불확실성·매핑·단위 관련 실제 모듈 결합 테스트 12개 로직 검증 완료 (Code Mode JS 실행). 별도 8개 자동 차원 추천 검증을 앞서 실시.
- 이 작업 세션에서 전체 `npm test` / Windows·Android Brave / 원본 PDF 픽셀 비교는 **NOT_RUN**; 120페이지 수기 QA는 **0/120**, 실제 디자인 일치율은 **미측정**. 위 로직 테스트 숫자를 전체 단위 테스트 통과 수처럼 보고하지 말 것.
- UBS FIN-16 벡터 경로는 변경하지 않음. SVG 구조 원본 비교 99% 목표는 여전히 별도 트랙이며 달성 주장 금지.
- 배포 전 GitHub branch SHA를 확인하고, Vercel `docut-studio`의 해당 SHA로만 1회 수동 배포. `vercel.json` git.deploymentEnabled=false 유지; CI, 설치 아티팩트, ZIP 생성 금지.
