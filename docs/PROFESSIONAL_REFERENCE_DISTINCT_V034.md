# DoCut Studio v0.34 — 실질적 레이아웃 분기 및 직접 잠금 제어

## 문제 인정

v0.33의 20개 세계적 기업 참조 카탈로그는 단 하나의 `buildPage` 공통 카드 배치를 사용했다. 개별 회사명과 색상 변경만으로 서로 다른 전문 디자인이라고 표기한 것은 실질적 구현 수준을 과장했다. 본 릴리스는 이러한 공통 생성기를 제거한다.

## 구현 원칙

- 20개 **독립 마스터 구조**: 회사 로고·원본 이미지를 복제하지 않고, 공개된 보고서의 정보 전달 방식을 연구해 별도로 설계한 편집형 웹-슬라이드 레이아웃.
- 매 마스터마다 6개 **구조가 다른** 본문 아키타입 연결. 총 120개에서 객체 종류/좌표/크기 기반 구조 지문이 모두 다르도록 테스트한다.
- 비슷한 이름의 템플릿을 늘리는 대신, 영역 비율·칼럼 순서·타이틀 위치·서술 스타일·인디케이터·표·차트·방사형 오브젝트를 다르게 구성한다.
- 첫 페이지뿐 아니라 각 마스터의 차이점이 6페이지에 지속된다. 문구, 수치, 출처 및 그림 원본은 자동으로 채워진 사실이 아니며 사용자 입력 전 비워 둔다.
- 원본 회사 브랜드의 공식 디자인/라이선스가 아닌 **독립 구현 레퍼런스**. 회사 명칭은 참조 정보로만 사용한다.
- 갤러리와 상단 6페이지 띠에 페이지 객체 자체로 만든 미리보기를 표시한다. 이전처럼 어디서나 동일한 텍스트형 직사각형 4개를 사용하지 않는다.
- 화면 중앙 잠금: 사용자가 요소를 클릭하면 상단 중앙에 열린 자물쇠와 '잠금'이 표시되며, 잠그면 선택 객체 **중앙에 닫힌 자물쇠 + 잠금 해제**가 표시된다. 잠긴 요소도 선택 및 해제 가능. 레이어 목록에서도 SVG 자물쇠로 동기화한다.
- 잠금 해제는 모델 값을 명시적으로 바꾸며 기존 Undo/Redo/프로젝트 JSON 저장 경로를 사용. 내보낸 최종 보고서에 편집 버튼이 들어가지 않는다.

## 실제 검증 게이트

1. 단위 테스트 515/515 통과(개발 내역 추가 후 최종 결과 기록).
2. 20개 팩의 첫 장 구조 지문 유일성 20/20.
3. 20개 팩 × 6장 구조 지문 유일성 120/120.
4. Deloitte/Meta 등 실제 브라우저 갤러리 시각 확인.
5. 자물쇠 선택→잠금→잠금 상태 선택→해제 브라우저 동작 확인.
6. v0.33 기능과 89종 효과를 제거하지 않고 호환성 유지.

**한계:** 리서치 대상의 실제 디자인을 페이지별로 픽셀 단위 복제한 것은 아니다. 공개 회사명/자료 링크와 독립적으로 설계된 UI 패턴을 연결하는 20개 자체 제작 방식이다. 실제 이용 데이터 입력과 한국어 폰트 환경/모바일 터치는 기기별 추가 확인이 필요하다.
