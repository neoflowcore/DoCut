## 1. 복원된 작업과 배경

v0.42는 01 McKinsey와 02 BCG를 독립 16:9 편집형 6페이지씩 구현했다. 03~20은 회사별 마스터가 없어 대부분 기존 `ART_DIRECTIONS` 공통 레시피를 사용하고 있었다. UBS만 기존 `DocutUBSVectorSource` 특수 경로를 가지고 있다. 이번 작업은 나머지 **17개 회사의 원래 공통 레시피 경로를 각각의 6페이지 전용 원본 생성 함수로 교체**한다.

디자인 출처: `docs/references/DoCut_Global_Professional_Reference20.json` / `docs/references/DoCut_Professional_Report_Reference20_Analysis.md`.

주의: 레퍼런스 기반 **정보 디자인 문법**(비율, 시각 계층, 선·음영, 차트 위치)을 바탕으로 새 코드를 작성한다. 저작권 있는 원본 PDF 페이지·로고·사진·인포그래픽·폰트·수치는 통합하지 않으며, 별도 사용 허가가 없으면 독립적으로 제작한 디자인이다. 특정 회사의 공식 템플릿이나 1:1 동일품임을 주장하지 않는다.

## 3. 코드/데이터 연결

1. `index.html`은 17개 전용 페이지 모듈과 기초 API를 `assets/pro_reports.js`보다 먼저 로드한다.
2. `DocutProReports.buildPage`는 팩 ID에 해당하는 **전용 디자인 모듈**로 라우팅. 01/02는 이전 전용 코드, 16은 UBS 특수 source-SVG 경로 그대로.
3. `page.designIdentity`는 네이티브 JSON 프로젝트 스키마·Undo·저장·재열기에 남도록 명시적 검증 후 보존한다. ID에는 정규식 허용 팩 코드만 기록.
4. `DocutDataPanel.suggestedPalette`은 선택 차트→현재 페이지 차트→페이지 고유 ID 순서로 **올바른 회사별 차트 색상**을 자동 추천한다. 빈 커버에 새 차트를 넣더라도 기본색으로 회귀하지 않는다.
5. 신규 17가지 회사 팔레트는 전부 native `C.CHART_PALETTES`에 등록하고, 동적 `option` 생성 시 `textContent`를 사용한다.
6. 사용자가 실제 엑셀 범위를 지정하기 전 차트 수치는 **[0,0,0,0] 자리표시**이며 `verified=false`. 이 값을 실제 실적이라고 표시해서는 안 된다.
7. 기존 v0.41 **XLSX 50 MiB / 300만 셀 / 10,000수식** 제한 유지. 시트 열 선택 UI에 256열 상한 적용.
8. 데이터 바인딩 차트는 360개 포인트까지 복원되도록 `core_enhanced.js`의 옛 120개 잘림 문제를 함께 해결. 도넛은 12개 범주를 유지하며 음수 데이터 금지.
9. 독립 HTML 내보내기는 C.CHART_PALETTES를 런타임 SVG 렌더러에 포함하고, 편집 가능한 네이티브 차트/표/도형 내용을 코드로 재생성한다.
10. 기본 페이지 모션은 `none`, 객체 효과 배열은 `[]`. 89개 효과 전수 검증은 별도 미완이다.
11. `assets/ubs_slot_recovery.js`의 비파괴적 복원 유틸리티와 `assets/app.js` 연결은 UBS source-ratio SVG가 늦게 준비되어 텍스트 입력 슬롯이 비어 있는 상태를 발견하면, 벡터 준비 이벤트·프로젝트 재열기·초기 로드에서 **원본 텍스트 슬롯만 자동 복구**한다. 빈 페이지에만 적용하므로 기존 사용자 텍스트/벡터 편집은 덮어쓰지 않는다. 이 복구 경로는 순수 함수 단위 로직 검증만 했으며 실제 브라우저 QA는 미실시다. 관련 신규 테스트: `tests/ubs_slot_recovery_v043.test.cjs`.

## 5. 실측 가능한 진척도 (혼동 금지)

- D0 레퍼런스 등록: **20/20 = 100%** (출처 등급은 자료마다 다름)
- D1 독립 6페이지 디자인 코드: **19/20 = 95%** (UBS 시범은 원본 일치 검증 필요)
- D2 회사별 native Excel 팔레트 연결: **19/20 = 95%** (UBS 기존 별도 엔진)
- D3 신규 독립 네이티브 페이지 기하·자료 구조: **114/114 = 100%** (정적 모델 체크 기준)
- D4 89 효과·전체 편집 UX: **미산정** (전수 재검증 없음)
- D5 사용자 브라우저/HTML 시각 동등성: **미산정**
- D6 실기검증·운영 배포: **0/120 = 0%**
- **DoCut 전체 제품 완성률/원본 디자인 일치율: 산정 불가** — 검증 가중치·정확도 측정치를 아직 갖고 있지 않음.
