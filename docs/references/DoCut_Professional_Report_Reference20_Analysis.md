# DoCut - 20 Public Professional Report Benchmarks

Research blueprint (2026-11-08). No production integration is claimed.

## Reading key

- `visual_pdf`: official PDF text and example pages reviewed.
- `official_index_only`: official publication index confirmed; exact PDF pages not yet visually inspected.
- `official_html_reviewed`: official report page reviewed, not necessarily its full PDF layout.
- `visual_pdf_prior`: source PDF screenshots were viewed in the research session, with the official page provided as a stable link.
- All proposed DoCut layouts are new, editable structures, not copied templates.

## Core design rules

1. Lead with the answer, supported by 1-2 evidence objects per slide.
2. Separate strategy, earnings, corporate, finance, and policy information models.
3. Enforce 16:9 with natural whitespace and flexible constraints. Split overfull material into additional pages; never hide content.
4. Preserve numbers, dates, measures, sources, footnotes, and link provenance through layout changes.
5. Use consistent typography, unit formatting, and column spacing.
6. Render clean tables with accurate current-vs-prior and YoY calculations.
7. All source assets remain link-only unless reuse is independently authorized.
8. Offer a six-slide interactive preview for each pack and user-controlled company-brand substitution.
9. Default animation: none; optional motion never alters numerical data or chart labels.
10. Do not expose official corporate branding on shipped imitation templates.

- Stage 1: STR-01, STR-02, EARN-06, FIN-17, PUB-18.

- Acceptance: 20 packs x six distinct slide archetypes = 120 editable layouts; batch tests for import, export, density, 16:9, typography, charts, source and undo/redo.
