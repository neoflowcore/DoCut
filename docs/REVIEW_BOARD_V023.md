# DoCut V0.23 — 내부 검토 의견·비공개 리뷰 교환

## 범위

이번 단계는 **인증·동시 공동편집이 없는 오프라인 보고서 편집기**에서 문서 리뷰를 관리하기 위한 기능이다. 기록은 실제 직원 인증, 공식 품질 심사, 수치·출처 사실 검증을 의미하지 않는다.

- `검토 메모` 또는 `Ctrl+Shift+M`으로 리뷰 패널을 연다.
- 보고서 전체, 현재 페이지, 현재 선택한 개체에 검토 의견을 추가한다. 의견에는 우선순위(높음/보통/낮음), 미해결/해결, 작성자 직접 입력(선택), 최대 16개 답글이 있다.
- 각 의견과 답글은 불신 입력으로 취급해 UI에서 *문자열만* 출력한다. 검토 의견은 원본 출처·기준일·수치 및 `verified` 플래그를 변경하지 않는다.
- 필터(상태·우선순위), 검색(의견·답글·작성자), 35건씩 더 보기, 위치로 이동, 연결이 끊긴 의견 다시 연결, 본문 수정, 우선순위 변경, 해결/재검토, Undo 지원.
- 페이지 썸네일에 미해결 건수 표시. 검토 후 개체 내용이 달라지면 *검토 시점과 현재 내용 지문의 비교*로 `원문 변경 후 재검토 필요`라고 안내한다. 이 지문은 비암호학적 참고값이며 승인이나 사실 검증이 아니다.
- `콘텐츠 점검`의 우선/검토 경고를 명시적 확인 후 **최대 20개** 내부 검토 메모로 복사한다. 같은 페이지·개체·메시지의 중복을 거른다. 수치 및 검증 표시를 수정하지 않는다.

## 데이터·개인정보 경계

검토 메모는 네이티브 DoCut 프로젝트의 `reviews` 속성으로 보존한다. 기존 schema=3 프로젝트는 이 속성이 없어도 열 수 있으며 빈 배열로 읽는다. 의견·답글 개수와 길이 제한을 넘으면 데이터를 잘라 버리지 않고 파일 가져오기를 **전체 거부**한다.

- `*.docut.json` 네이티브 프로젝트, 로컬 자동저장, 복구 백업에는 `reviews`가 **포함**된다. 이름·내부 기록이 들어 있으므로 외부 공유 전 주의한다.
- 공개용 `HTML`·HTML 코드 TXT·본문 요약 TXT·기본 AI 제작 프롬프트·PPTX에는 `reviews` 내용이 **자동 포함되지 않는다**. 공개 HTML은 검토 기록의 왕복 파일로 사용하지 않는다.
- 리뷰 기록을 TXT 또는 Excel 호환 CSV로 별도 다운로드할 수 있다. CSV는 Excel 수식처럼 시작하는 입력 앞에 `'`를 붙이고 셀·따옴표·개행을 인용한다.
- `검토 의견 공유용 JSON`은 **보고서 원문·표·이미지를 포함하지 않는 리뷰 전용 패킷**이다. 작성자 이름·메모는 들어 있다. 공유·전송은 사용자의 명시적 파일 저장·전달만으로 진행한다.
- 공유 패킷을 가져오면 원본 `createdAt`으로 문서 원형을 맞춰보고 새 의견·중복·고립된 의견 수를 미리 표시한다. 사용자가 체크해 승인하기 전에는 변경하지 않는다. 같은 ID가 서로 다른 내용이면 무단 병합·덮어쓰기를 거부한다. 300개 상한과 저장 전 안전 백업을 적용한다.
- JSON 파일 읽기 도중 보고서가 바뀌거나, 미리보기 후 보고서가 바뀌면 병합을 중단하고 다시 검토한다. 백업 저장소가 가득 차면 현재 문서 JSON을 내려받고 재시도한다.

## 의도적인 비기능

실시간 협업, 작성자 계정 인증, 서버 동기화, 온라인 권한 설정, 암호학적 서명, 공식 결재, 모바일 알림·푸시, Word 코멘트/PowerPoint 코멘트 OOXML 왕복은 구현하지 않는다. 공개 HTML을 가져와도 내부 의견이 복원되지는 않는다. 삭제된 원본 개체에 연결된 의견은 데이터 손실 방지를 위해 연결 끊긴 상태로 남겨 사람이 재연결하도록 한다.

## 테스트 범위

- 신규 Node 단위검사: 입력 검증, 300건·16답글 한도, 복원·Undo 보존, 해결 후 원문 변화 감지, 프로젝트 내 ID 복사/병합, CSV 수식 안전성, 공개 HTML에 리뷰 정보 미포함, 공유 패킷 충돌·중복·일치 검사 등.
- 신규 Chromium 합성 로컬스토리지 검사: 다이얼로그·390px 모바일·품질 경고 전환·결정 상태·위치 이동·편집·답글·파일 저장/분리/승인·악성 HTML 불실행.
- 실제 Windows/Android Brave 및 PowerPoint 프로그램을 이용한 실기 검증은 별도. 자동 브라우저만으로 실제 기기 PASS라고 할 수 없다.
- 인수 기준 42/53(79.2%)은 이전 V0.15 고정 인수 기록이다. 이번 단계가 V1.0 전체 완성을 의미하지 않으며, 89장 디자인 일치율은 아직 측정하지 않았다.
