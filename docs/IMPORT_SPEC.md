# DoCut 파일 가져오기/AI 제안 적용 규약 · V0.9.1

## 1. 입력 모드

- **native**: DoCut HTML의 `<script id="docut-project" type="application/json">`에서 프로젝트 JSON을 읽어 정규화한다. 좌표·모션·속성·레이어 그룹·검증 필드·페이지 작성 질문을 복원한다. 손상 데이터는 임의 복구하지 않고 오류를 낸다.
- **layout**: 외부 HTML에서 inline `position:absolute/fixed`, 명시적 `left/top/width/height`가 있는 블록을 선택해 1280×720 좌표로 근사 매핑한다. 위치·크기·문구·일부 색상·폰트 크기를 편집 가능한 요소로 복원한다. **원본 CSS 레이아웃 재현을 보장하지 않는다.**
- **generic**: 외부 HTML을 실행하지 않고 `h1`~`h3`, `p`, `li`, `table` 등 의미 구조로 변환한다. 원본 복잡한 스타일은 유지하지 않는다.
- **txt**: 일반 TXT의 구분선·헤딩을 간단한 페이지 흐름으로 변환한다.
- **json**: DoCut 프로젝트 스키마를 정규화한다. DoCut 저장본을 재편집한다.

## 2. 신뢰 경계

- 제3자 HTML에서 `script/style/iframe/object/embed/template/noscript` 노드를 제거하고 임의 스크립트·외부 이미지 로드를 실행하지 않는다.
- DOM 텍스트/테이블 셀만 추출하고 렌더 시 HTML 특수문자를 이스케이프한다. `[color=#RRGGBB]...[/color]` 등 허용된 제한적 부분 서식만 렌더한다.
- 외부 페이지의 URL을 무조건 신뢰하지 않는다. 이미지 데이터는 JPEG/PNG/WebP Base64의 제한된 크기만 수용한다.
- 8MB 파일 입력, 50페이지, 페이지당 150개 요소, 요소당 최대 3개 모션, 최대 12개 차트 값/20×8 셀 제한이 적용된다.
- 가져오기는 현재 프로젝트 복구본을 남긴 뒤 교체한다.

## 3. AI 제안 JSON 반영

- AI 제작 프롬프트는 프로젝트 전체의 제목·페이지·구성·근거 상태를 포함한다. 확인되지 않은 통계·사실을 생성하지 말라고 지시한다.
- AI가 반환한 JSON은 실행 코드가 아니라 **데이터**다. `ai-bridge`에서 텍스트를 파싱, 정규화, 변경 항목을 요약하고 사용자 명시 적용 버튼이 눌릴 때만 교체한다.
- 데이터와 지표가 바뀌면 `verified=false`로 취급한다. AI가 변경 지표에 `verified=true`라고 넣더라도 자동 승인하지 않는다.
- 적용 전에 현재 문서 로컬 백업과 Undo 체크포인트를 남긴다.
- 이 단계는 원격 API를 호출하지 않는다. JSON 붙여넣기 방식으로 작동한다.

## 4. 출력

- DoCut HTML은 CSS/JS와 데이터 프로젝트를 포함한 단일 파일이며 오프라인 단독 실행이 가능하다.
- TXT (HTML 코드)는 확장자를 HTML로 바꾸면 동일한 보고서 코드를 제공한다.
- 본문 요약 TXT는 슬라이드 문구와 차트/표의 내용을 순서대로 보존한다.
- `.docut.json`은 장면 편집용 원본. CSV는 표/차트용 데이터 별도 출력.
- 브라우저 인쇄 스타일은 모든 페이지를 16:9로 펼치지만, 별도 PDF 파일 생성기는 제공하지 않는다.


## V0.10 변환 진단

- native/json: DoCut 스키마의 레이어/모션을 복원.
- layout: 타사 HTML의 인라인 절대좌표를 근사 변환하되 CSS/스크립트 재현 불가를 명시.
- generic/txt: 의미 단위로 재구성, 원형 픽셀 레이아웃 복원 불가를 명시.
- 진단 UI는 페이지·요소·표·내장 이미지 개수의 실제 수치만 표시하며, **근거 없는 시안 일치율 퍼센트는 표시하지 않음**.
