# DoCut Studio V0.11.0 · 개발 마일스톤 및 실제 확인 상태

**기준:** 2026-11-02 (KST) · 로컬 소스와 자동 테스트 기준. 실물 기기·PowerPoint 수기 검증 보류.
**프로젝트:** `neoflowcore/DoCut` · 소스 브랜치 후보 `main`.

## 재개 기준선

- V0.10.0 로컬 소스, 35개 기존 테스트, 계획 문서 복원 후 V0.11.0으로 확장.
- 원격 DoCut GitHub 저장소는 조회되었지만 파일/브랜치가 없는 빈 저장소임을 확인.
- GitHub 파일 쓰기 API 재시도는 `403 Resource not accessible by integration`으로 실패. git HTTPS Push는 컨테이너의 `github.com` DNS 접근 실패. 로컬 Git 단일 묶음 커밋은 생성되었지만 **원격 업로드는 미완료**.
- GitHub Actions 워크플로 없음. 자동 CI, 설치 EXE/APK/ZIP, 릴리스 빌드를 하지 않음.

## V0.11.0 소스에 적용된 개선

1. **페이지/레이어 탐색:** 실제 좌표 기반 페이지 썸네일, 페이지 순서 드래그, 레이어 순서 드래그와 키보드 단축키, 전체 보고서 검색, 페이지 간 복사·이동. 그룹명/ID 복원 시 중복을 제거.
2. **편집 손실 방지:** 레이아웃 프리셋 변경 기본값을 비파괴 재배치로 전환, 내용·근거·미검증 표시·모션 데이터 유지. 데이터가 없어도 신규 요소 빈 공간 우선 배치.
3. **표/차트:** 셀별 배경색·문자색·굵기·정렬, Excel 탭 데이터, 5가지 차트 팔레트, 음수 데이터 영점 렌더링, CSV 공식 시작 문자열 안전화.
4. **모션:** 요소별 3개 슬롯 유지, 직접 중간 키프레임 최대 4개, 시간값과 포즈 편집, 모션 조합 프리셋 5종, 가시 요소에 125ms 순차 적용, 합성 모션/스크럽.
5. **공통 브랜딩:** 전 페이지 푸터·페이지 번호·내장 이미지 로고. 로고 내용은 JSON·HTML·PPTX 정적 모델로 전달.
6. **품질 피드백:** 편집 중 과밀한 텍스트·명도 대비 추정 경고, 샘플/출처/미검증 확인, 요소 위치 이동, 근거·검증 상태 TXT 내보내기.
7. **외부 HTML 가져오기:** 변환 신뢰 유형 설명 및 편집 요소 개수·표 개수 진단, 자체 HTML 복원/일반 HTML 재구성/좌표 추정 구분.
8. **프로젝트 병합:** 파일 불러오기에서 현재 문서 교체와 뒤에 페이지 추가 선택. 원본 제목·테마·브랜딩을 지키고 신규 페이지/그룹/요소 ID를 재발급, 50페이지를 초과하면 취소.
9. **모바일 세로 UI:** 390×844 개발 브라우저에서 캔버스 공간을 높이 270px로 축소하고 요소 도구 패널을 359px로 확장. 실제 Android 검증과는 구분.
10. **도형 및 스타일:** 테두리 두께·색상, 이미지 마스크·초점, 부분 서식, PPTX 정적 편집 객체 변환.
