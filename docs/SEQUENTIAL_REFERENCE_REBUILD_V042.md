## 데이터 연결 및 비파괴 규칙

1. 갤러리에서 6페이지 삽입 → 차트 객체 선택 → `데이터 연결`로 XLSX/CSV 업로드.
2. 기존 차트 `bar/line` 유형과 전용 색 팔레트 우선 보존. 단위와 원자료 수치는 자동 변경하지 않고 사용자가 검토/승인.
3. 표와 차트는 네이티브 편집 객체. 효과는 기본 **OFF**, 프레임은 **1280×720**, 모든 페이지별 독립 객체 120개 이하.
4. 샘플 수치는 모두 0 또는 미입력으로 취급. 출처/조사일 미확정 상태는 텍스트로 명확히 표시하고 검증 마크를 붙이지 않음.
5. JSON/독립 HTML 내보내기는 사용자 입력값과 선택된 그리드·팔레트를 유지해야 함.
6. PDF의 특정 원본 숫자, 기업명, 로고 및 사진을 페이지 데이터에 그대로 끼워 넣는 눈속임은 금지.
