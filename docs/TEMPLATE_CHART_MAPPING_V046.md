# DoCut v0.46 — 20종 전문 템플릿 Excel 차트 자동 매핑 및 묶음 분리

- **기준 저장소/브랜치:** `neoflowcore/DoCut` / `main`
- **이전 체크포인트:** v0.45 `aab36a267800438812843449ffd27b8490e60189`
- **범위:** 20개 레퍼런스 × 6페이지 구성(총 120페이지 경로). **19종 네이티브 독립형 114페이지**에 템플릿 차트 자리 연결. **UBS는 별도의 source-ratio SVG 6페이지 시범**이며 v0.46 자동 다중 매핑은 적용하지 않는다.
- **검증 표기:** 소스 생성·JS 모델 테스트와 브라우저 실기검증·공식 PDF 시각 대조는 별도 단계. 임의로 99% 시각 일치율을 주장하지 않는다.

## 1. 개발 목적

기존에는 엑셀 파일에서 생성한 막대·선·도넛을 빈 페이지에 별도로 추가하거나, 사용자가 특정 차트를 선택하고 매번 직접 데이터 열을 연결해야 했다. 원본 레퍼런스의 레이아웃이 흔들릴 수 있었다. v0.46은 **페이지에 이미 정의된 회사별 빈 차트 영역에 데이터 값만 채우고 위치·크기·팔레트·ID를 보존**한다.

새로운 자동 배치는 완전 비어 있는 영역이 있을 때만 사용하며, 이미 본문을 차지하는 영역에는 경고를 노출한다. 각 보고서 요소의 배치는 100% 벡터/CSS/JS 네이티브이며, 원본 PDF 화면을 이미지로 덮지 않는다.

## 2. 구현된 기능

| 기능 | 구현 상세 | 안전성/한계 |
|---|---|---|
| 원본 차트 슬롯 마커 | 회사별 생성기에서 `templateSlot=true` 지정, JSON 저장·재열기 허용 | 사용자가 만든 **값 0인 차트**라는 이유만으로 슬롯 추정하지 않음 |
| 현재 페이지 자동 슬롯 선택 | 사용자가 선택한 원본 차트 우선, 일치 유형 우선, 유일한 슬롯이면 원래 타입 유지 | 기존 원본 차트 ID·x/y/w/h/색상·장식 유지 |
| 새 차트 배치 | 원래 제목·본문·차트와 겹침을 최소화하는 좌표 탐색 | 배치 공간이 부족하면 겹침 경고, 실브라우저 편집 확인 필요 |

## 4. 엑셀 숫자 및 결과 출처 정책

- XLSX 50 MiB 압축, 최대 3,000,000셀, 수식 최대 10,000개 제약은 이전 엔진 유지. 실행 기기의 메모리 요구량은 별도.
- 실제 원본 5,000셀 이하는 셀 스냅샷 전체 보관. 초과 시 분석 후 연결된 **차트별 계산 결과만** 파생 시트에 저장한다. 원본 파일명을 남기고 재분석이 필요하면 XLSX 재업로드 안내.
- CSV 숫자 코드 `00123`은 문자열 식별자로 보존. 자료명·시트·범위·열 제목을 기록한다.
- 동일 열·다른 헤더 충돌은 점수 차이를 요구한다. 차트와 관련 없는 헤더는 일괄 자동 채우지 않는다.
- 업로드한 수식 캐시와 현재 엔진 계산 범위 밖의 함수는 재계산하지 않는다. **표시값이 참인지 작성자가 검토**해야 한다.
- 360포인트 차트는 기존 구현을 유지. 집계 후에도 차트 점이 과다한 경우 자동으로 자르지 않고 예외를 표시한다.

## 5. 실기검증 사전 절차 (현재 **NOT_RUN**)

**중요: 사용자 요청 이전에는 운영 배포·실기검증·GitHub Actions·EXE/APK/ZIP 생성하지 않는다.**

1. **커밋 확인:** GitHub `main` 최종 SHA, `package.json`과 웹앱 버전이 일치하는지 확인.
2. **최종 배포:** 실기검증이 명시적으로 요청되면 Vercel 또는 Cloudflare의 정확한 DoCut 프로젝트에 최신 SHA를 한 번 수동 배포. 배포 상태 READY 및 배포 SHA 일치 확인.
3. **20종/120페이지:** 모든 회사별 6페이지 열기·텍스트 편집·잠금·크기 변경·페이지 전환·저장/재열기. UBS 6페이지는 원본 SVG 로딩 후 빈 슬롯 복원/기존 수정 보존 검증.
4. **원래 차트 자리 보존:** McKinsey, BCG, Bain, NVIDIA, BlackRock 등에서 차트로 선택→실제 엑셀 연결. 크기, 위치, 색상, ID, 원본 비주얼 요소가 변하지 않는지 비교.
5. **6페이지 자동 매핑:** Bain 템플릿의 투자 거래액과 회수액 헤더가 바/라인에 다르게 연결되는지, ‘회수액/회수량’처럼 모호한 수치를 보류하는지 확인.
6. **두 묶음 격리:** Bain 6페이지를 두 번 생성→두 번째 묶음에서만 연결. 첫 번째 묶음 6장 값은 원래대로인지 확인. 기존 v0.45 저장 파일도 검사.
7. **오류 시 원본 보존:** 잠긴 차트, 기존 연결 차트, 시트 미일치, 값 결측, 계산 불가/숫자 한도/파일 한도, 문서 검토 후 변동을 차례로 주입. 정상 문서에 값이 부분 적용되면 실패.
8. **대용량 엑셀:** 7,100셀·10,100셀·780,002셀·3,000,000셀 근접 파일을 단계적으로 업로드. 브라우저 UI 응답/메모리와 차트 스냅샷의 값·원본 출처 기록.
9. **독립 HTML:** 내보낸 HTML을 오프라인 열어 실제 숫자·음수·0·식별자 `00123`·단위·회사별 색상·페이지 전환을 확인.
10. **시각 정확도:** 실제 공식 레퍼런스 PDF와 각 네이티브 화면 캡처를 동일 비율로 놓고 레이아웃·타이포·대비·음영·도형 위치를 정량 비교. **99% 디자인 일치율은 측정 전까지 미표기.**
