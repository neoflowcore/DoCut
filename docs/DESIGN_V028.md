# DoCut v0.28 — 실제 효과 스튜디오·복합 광원·브랜드 제어

2026-11-06 기준. 작업 브랜치 `main`, 복원 기준 v0.27 `aeec3b2`.

## 사용자 문제와 구현 결과

1. **효과가 있는데 화면에서 보이지 않음:** v0.27의 `cursor-glow`, `ambient-aura`, `edge-light`는 동일 `::after`에 효과를 기록해 복수 선택 시 상호 덮어쓰는 문제가 있었다. v0.28은 `DocutInteractionFX.markup()`이 카드 자식 레이어를 **앰비언트/엣지/커서 별도 DOM 스팬**으로 생성한다. 실제 텍스트는 별도의 `element-inner` 위계에 남는다. 카드당 최대 3개의 효과를 유지한다.
2. **89개 참고 자료를 찾기 어려움:** 상단 / 디자인 탭 / 선택 카드의 모션 스택에서 `효과 스튜디오`를 열 수 있다. **32개 실행 효과**와 **33개 실행 조합 프리셋**을 검색·분류·미리보기·재생·적용한다. `89장 레퍼런스 인덱스`로 파일명/설명 목록을 직접 열 수 있다. 89장 JPG는 서로 다른 실행 애니메이션 89개가 아니다. 원본 이미지 바이트는 이번 파일에 포함되지 않는다.
3. **한 박스에 조명과 마우스 반응이 겹쳐지지 않음:** 3개 독립 광원 레이어, CSS 사용자 정의 속성, `pointermove` 위임 핸들러 및 공개 HTML 재사용 런타임으로 보완. 편집 전용 가짜 애니메이션이 아니다. 선택 카드에 한해 광원 색상, 강도, 반경, 3D 기울기 최대각, 엣지 이동 속도를 직접 변경하고 프로젝트 JSON과 HTML 내보내기 결과에 저장한다.
4. **배경만 투명하게:** `style.backgroundOpacity`는 `background` 색상의 RGBA에만 곱하고 `style.opacity`/본문/차트 레이어에는 곱하지 않는다. `#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`, `rgb()`, `rgba()`를 범위 검증하며 입력 불허형 CSS는 투명색으로 제한한다.
5. **로고 / 전체 글꼴:** v0.27의 원형 기본 로고, 크기·여백, 상하·중앙 포함 총 8개 위치, 10개 글꼴을 유지한다. 전체 글꼴 적용은 잠긴 레이어를 기본 보호하고 `잠긴 텍스트 레이어까지 포함` 사용자가 체크한 경우에만 일괄 변경한다. 실행 취소 가능.
6. **20개 템플릿:** 기존 10개 + 신규 10개 고급 보고서 페이지 키트, 9개 팔레트와 구조 미리보기를 유지한다. 타사 템플릿 자산/로고를 그대로 복제하거나 예시 KPI를 사실인 것처럼 삽입하지 않는다.

## 전용 모듈 및 코드 경계

- `assets/effect_studio.js`: UI 모달, 검색/카테고리, 실제 `DocutExporter.renderBlock()` 샘플, 동작 재생/리플레이, 선택 개체에 대한 명시적 적용만 허용.
- `assets/interaction_fx.js`: 편집기와 공개 HTML에 같은 CSS/포인터 런타임, 독립 레이어, 시스템 `prefers-reduced-motion` 준수. 이동광 효과는 유한 2회이고 자동 무한 반복을 두지 않는다.
- `assets/core_enhanced.js`: `fxLightColor`, `fxGlowStrength`, `fxGlowRadius`, `fxTiltStrength`, `fxEdgeSpeed`의 범위·색상 검증 및 가져오기 정규화.
- `assets/export.js`: HTML, 캔버스, 독립 HTML 공개 파일에 동일한 효과 마크업·색상·속성 반영. `python tools/sync_export_runtime.py`가 내장 런타임을 수동 동기화.
- `assets/app.js`: 효과 미리보기/적용, 밝기·각도·속도·글꼴 잠금 포함 옵션, Undo, 89 인덱스 진입점.
- `assets/branding.js`: 배경 RGBA 조합, 로고 8위치와 글꼴 안전값.

## 사용법

1. 왼쪽 `디자인` → **프리미엄 템플릿 20종 보기**에서 레이아웃을 실제 화면으로 미리보고, 기존 페이지를 유지한 채 새 페이지를 추가한다.
2. `구성` → 카드 레이어 선택 → 오른쪽 `모션 스택`의 **효과 스튜디오** 또는 상단 **효과 미리보기**를 연다. 효과 검색/카테고리를 고르고 미리보기 카드 위로 마우스를 이동해 반응을 확인한다.
3. 효과를 명시적으로 적용하면 오른쪽에 `라이트·커서 반응 조절`이 보인다. 강도·반경·빛 색상·각도를 변경해 카드별 시각효과를 조정한다.
4. 오른쪽 `스타일`에서 **배경 불투명도**만 낮춰 글자는 선명하게 둔다.
5. 왼쪽 `디자인` → **로고·전체 글꼴 설정** → 우상/우하/중앙 등 로고 위치와 원형·크기 조절. 글꼴을 고르고 `전체 적용` 클릭. 잠금 요소는 필요한 경우에만 체크한다.
6. 상단 `프로젝트`로 편집 원본 JSON을 백업하고, `내보내기` → 독립 HTML로 실제 모션이 포함된 발표용 문서를 저장한다.

## 검증과 남은 한계

- Node 단위 및 HTML 구성 검사, Chromium 합성 브라우저 선택/적용/포인터 반응/광원 오버레이/글꼴/알파/독립 HTML 내보내기를 대상으로 한다. 실제 Windows Brave·Android Brave·PowerPoint 실기 통과는 주장하지 않는다.
- 오프라인 단일 HTML 편집기 빌드는 `tools/build_standalone_editor_v028.py`; 이것은 설치 프로그램, EXE/APK/ZIP, 서버 배포가 아니다.
- 외부 HTML을 모든 서식/모션까지 무손실 복원하는 기능, 글꼴의 OS별 설치/표시 동일성, 원본 JPEG 89장과의 픽셀 일치율, 브라우저 출력과 PowerPoint의 3D/마우스 모션 동등성은 미검증이다.
- GitHub 원격 `neoflowcore/DoCut`의 연결 앱은 이번 세션에서 Git 데이터 쓰기에 **HTTP 403**을 반환했다. 로컬 Git 커밋과 원격 Push를 혼동하지 않는다.
- 기존 Vercel 프로젝트 `docut-studio`의 READY 배포는 v0.28을 자동으로 반영하지 않는다. `vercel.json`의 `git.deploymentEnabled=false` 정책을 보존한다.
