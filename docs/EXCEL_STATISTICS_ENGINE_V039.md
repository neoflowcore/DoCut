# DoCut v0.39 - Excel Statistical Chart Engine

## Decision
UBS is an editable layout preset. Exact original UBS bar heights and numbers are not the target. Users upload their own Excel table; DoCut generates editable SVG charts with the UBS-like palette and native layout coordinates. Preserve surrounding headings, guide lines and negative-value baseline.

## Features implemented
- Reuse the offline browser XLSX/CSV/TSV importer, sheet picker, A1 range selector, column roles, header, optional period filter, data provenance, native dataset snapshots and JSON/HTML export.
- Automatically detect header, category, numeric column and recommended chart/mode.
- Descriptive statistics: sample count, sum, mean, median, min/max, sample standard deviation and variance, quartiles, first/last, signed delta and percent change.
- Transformations: raw source order, grouped categories with sum/mean/count/min/max/median/last, configurable histogram 2-30 bins, cumulative series. Missing/invalid numeric values and missing formula caches are reported as errors, never silently zeroed.
- Render up to 120 bars or line points, including negatives, a true 0 baseline, grid lines, accessible SVG title per value and the UBS gold palette.
- Automatic UBS bar/line placement for source PDF pages 13 and 16, using original-aspect coordinates transformed to the 1280x720 editing frame. This is an editable replacement overlay, not a copy of source figures.
- Standalone HTML includes matching, updated analytics and data-motion runtimes. Chart remains linked to included source cells. The chart can also be edited via the ordinary DoCut element inspector.
- The parser never executes spreadsheet formulas, macros or external links.

## Operator path
1. Page Kit / UBS original / six pages / PDF page 13 or 16.
2. Data connection / upload Excel .xlsx or CSV / pick sheet, full used range (default), category and number columns.
3. Review the numeric statistics and select raw/group/histogram/cumulative plus aggregation.
4. Select UBS gold chart and the source chart placement toggle; review and insert.
5. Export native JSON or standalone HTML; the data values are not embedded as external third-party asset references.

## Limits and reporting
- XLSX 12 MiB, 1000 rows, 30 columns and 30000 cells per sheet (parser-defined limits); 120 points per bar or line chart, 12 donut slices and native DoCut project storage limits remain.
- No formula recalculation, Excel macros, native Excel chart extraction, pivot tables, regression/forecasting, or automated multi-metric axis modeling yet.
- This is an Excel-to-SVG authoring feature, NOT a claim of 99% UBS browser pixel similarity. The UBS original vector PDF graphics and browser screenshots are separate acceptance gates; full UBS six-page 99% browser fidelity remains unverified.
