## GitHub 및 비용

- 저장소: `https://github.com/neoflowcore/DoCut`, 기본 브랜치 `main`, 앞서 비어 있음을 확인.
- GitHub 통합의 파일 생성 작업: `403 Resource not accessible by integration`.
- 따라서 **GitHub 업로드 미완료**. 새 GitHub 사용자 승인 요청 없이 구현 및 로컬 검증 계속.
- `.github/workflows/` 없음. GitHub Actions 자동 실행·CI·EXE/APK/ZIP 산출물 생성 금지.
- 기능 통합 이후 로컬 Git 1개 묶음 커밋을 기준선으로 저장하고, 통합의 쓰기 권한이 회복되면 소스만 Push할 것.

## 실기검증에 앞선 잔여 개발 백로그

1. 타사 HTML 레이아웃 원형 복원 정확도 향상(변환 모드·진단 UI는 구현), 외부 이미지/폰트 에셋 처리.
2. 이미지 크롭·4종 마스크와 기본 부분서식은 구현; 정밀 부분 텍스트 조판, 레이어 폴더·스마트 정렬 추가 고도화.
3. 시간축 스크럽, 2점 시작/끝 키프레임, 베지어 수치 편집 구현; 중간 키프레임 및 시각적 곡선 에디터 추가 고도화.
4. 정적 편집 가능한 PPTX 코드 구현·메모리 직렬화 검증. 영상·고품질 PDF 및 PPTX 모션 완전 이식은 향후 범위—**지금 설치 아티팩트 생성 없음**.
5. 원격 AI 연동은 보안/비용 선택 사항. 로컬 프롬프트/JSON 리뷰는 작동.
6. 개발 범위 완성 후 Windows/Brave/Android 실기 PASS, 그 직전에만 단일 빌드가 필요한 경우 생성.
