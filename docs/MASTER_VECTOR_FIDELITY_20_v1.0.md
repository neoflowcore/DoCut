# DoCut — 글로벌 전문 보고서 20종 벡터 정밀복원·시각검증 실행계획 v1.0

- 기준일: 2026-11-08 (Asia/Seoul)
- 기준 제품: DoCut Studio 0.34.0 / 고도화 구현 지점 0.35.0-development
- 범위: 20개 보고서 계열 × 최소 6개 서로 다른 본문/표지 유형 = 검증 단위 120개
- 첫 파일럿: UBS *Global Wealth Report 2025* 공개 원본의 편집 문법 → 독립적인 16:9 벡터 구조 시안. 2026 원본과 동일하다고 주장하지 않음.
- 완료 표기: **실측 기준과 원본 증거가 준비된 개별 페이지만 PASS**. 페이지가 존재한다는 이유로 99%라고 표기하지 않는다.

## 0. 결정 사항과 불가능한 약속

**지향점은 본문·숫자·로고·저작권 보호 이미지와 별개로, 화면 뼈대의 위치·크기·선·색·그라데이션·음영·차트 그래픽을 코드 기반 벡터로 정밀 복원하는 것이다.** HTML·CSS·SVG로 충분히 높은 충실도를 구현할 수 있으나, 99%는 *측정 가능한 목표치*이지 소스만 보고 보장할 수 있는 결과가 아니다. 플랫폼·서체의 앤티앨리어싱·색 관리·PDF 그림자 및 원본 사진의 영역까지 포함하면 100%는 일반적으로 재현할 수 없다.

**서로 다른 두 모드를 분리한다.**

1. `SOURCE_RATIO`: 원본 PDF/이미지의 페이지 크기·종횡비·도형 좌표계를 유지한다. 동일 렌더링 조건, 텍스트/숫자 마스크로 99% 목표를 평가할 **유일한 픽셀 유사도 경로**다.
2. `EDIT_16_9`: DoCut 편집기 1280×720 화면에 적합하도록 분할·크롭·변환한 별도 벡터 레이아웃이다. 원본에서 유래한 편집 문법은 검증하되 **원본 PDF와의 픽셀 99% 일치율로 표시할 수 없다**. 두 모드 점수 합산 금지.

사용자가 요구한 “문자와 숫자를 제외한 뼈대”는 *텍스트가 들어갈 프레임의 위치/행간/최소 높이는 그대로 측정*하되 실제 글리프만 비교에서 제외한다는 뜻으로 구현한다. 무의미하게 넓은 직사각형을 마스킹하면 실패하도록 제한한다.

## 1. UBS 원본 기반 1차 진단 (검증 자료와 한계)

- 2026 공식 배포 페이지: https://www.ubs.com/global/en/wealthmanagement/insights/global-wealth-report.html — 공식 내려받기에 신청 양식이 보이며, **이번 단계에 2026 전체 PDF 원본 이미지가 확보되었다고 주장하지 않는다**.
- 2025 공개 원본 PDF: https://www.ubs.com/content/dam/assets/wm/static/noindex/gwr-2025-digital.pdf
- 2025 대체 공개 링크: https://advisors.ubs.com/mediahandler/media/715872/UBS%20Global%20Wealth%20Report%202025.pdf
- 소스 기반 시각 확인: 2025 Welcome 페이지의 상단 홈 아이콘/가느다란 네비게이션, 빨간 현재 장 표시, 베이지색 좌측 편집 영역, 원형 초상 프레임, 큰 제목, 오른쪽 2단 본문, 세로 빨간 인용 강조선과 하단 주석/콜아웃. 본문의 자산 분포 차트는 원형/도넛형, 다른 장은 수치 비교표와 긴 주석을 사용.
- 과거 DoCut FIN-16의 크림색 다이아몬드 피라미드·카드 배치는 실측 좌표가 없으며 **원본의 정밀 재현품으로 표시할 수 없었다**. 이 기준으로 개선한다.
- `assets/ubs_fidelity.js`는 원본 PDF의 저작권 있는 사진/로고/QR/문자를 포함하지 않으며, **웹용 16:9 어댑테이션을 기존 DoCut 편집 객체로 벡터 재구성한 파일럿**이다. 현재 유사도 `N/A`, 시각검증 `UNVERIFIED`. 정밀 원본 좌표 보정은 다음 게이트.

## 2. 정밀 구조 벡터 스키마

원본을 `ReferenceDocument → PageSpec → Layers → Primitives → Paints → Effects → TextRegions → DataRegions` 계층으로 해체한다.

```json
{
  "id": "FIN-16-2025-p03",
  "sourceUrl": "https://www.ubs.com/content/dam/assets/wm/static/noindex/gwr-2025-digital.pdf",
  "sourceEdition": "2025",
  "sourcePageIndex": 2,
  "originalSize": {"width": null, "height": null, "unit": "pdfpt"},
  "mode": "SOURCE_RATIO",
  "coordinateSpace": "normalized-0to1",
  "layers": [
    {"role": "background", "primitive": "rect", "bbox": [0,0,1,1], "fill": "#FDFCFA"},
    {"role": "section-accent", "primitive": "rect", "bbox": [null,null,null,null], "fill": "TBD_FROM_PDF"},
    {"role": "content-slot", "primitive": "rect", "bbox": [null,null,null,null], "stroke": "TBD_FROM_PDF"}
  ],
  "textBoxes": [],
  "measurements": {"score": null, "status": "unverified"}
}
```

- 도형: `<rect>`, `<line>`, `<path>`, `<circle>`, `<ellipse>`, 다각형, 캔버스 도형을 모두 SVG 좌표로 정의한다.
- 선: CSS/SVG `stroke-width`, 선 끝 모양, 점선 패턴, 0.5px 헤어라인, 캡/조인까지 검증한다.
- 색: 원본 PDF 추출의 sRGB/Lab 팔레트, 색상값·명도·불투명도를 각각 저장하며 임의로 ‘비슷한 색’ 사용 금지.
- 음영: `feGaussianBlur`, `feDropShadow`, `linearGradient`, `radialGradient`, opacity, inner shadow, 혼합 모드, 클리핑 순서를 효과 레이어로 표현한다.
- 차트: 원본 수치 그래픽은 사진으로 붙이지 않고 SVG 세그먼트·곡선·막대·축·격자·범례로 분해한다. 원자료는 미확인인 상태에서 그럴듯한 숫자를 채우지 않는다.
- 서체: 실제 라이선스와 제공 여부 확인. 사용할 수 없으면 폴백을 표시하고 본문을 가린 채 **텍스트 박스 기하**로 별도 평가한다. 서체 차이로 도형이 이동하지 않게 고정 기준선을 둔다.
- 그림·사진: 기존 저작권 있는 이미지는 공개 근거로만 확인하고 제품 내 템플릿에 복제하지 않는다. 벡터로 독립 제작 가능한 도형만 제공한다. 사진 재현이나 기업 로고의 오인 방지가 필요하면 해당 영역은 비교 대상에서 명시적으로 분리한다.
- 모든 장식 레이어를 다시 개별 편집/잠금/드래그/순서 조절 가능하도록 유지한다. 완성본을 하나의 배경 PNG로 합치는 것은 불합격.

## 3. 측정: `tools/visual_fidelity_score.py`

각 증빙 쌍은 (1) 독립적으로 내려받은 원본 PDF의 **확정된 페이지**, (2) 같은 비율/동일 해상도로 캡처한 DoCut 벡터 렌더링, (3) 비텍스트 마스크가 허용되는 목록, (4) 캡처 환경과 해시를 포함한다.

1. 먼저 PDF 원본과 시안의 페이지 크기·방향·내용 ROI를 일치시킨다. 늘려서 비교하거나 임의 크롭 금지.
2. 텍스트·숫자·등록된 로고 영역의 글리프만 좁게 마스킹한다. `mask >35%` 또는 차트 전체 은폐면 측정 실패. 원본/PDF 텍스트 좌표 추출을 우선한다.
3. 동일 크기의 PNG로 `SSIM 구조`, `Canny 경계 F1(오차 허용 2px)`, `RGB 색 오차`, `저주파 명암·음영 기울기` 네 가지 점수를 측정한다. 흰 배경만 맞고 그래픽이 비어 있는 시안이 높은 점수를 받지 않도록 전경과 경계에 가중치를 준다.
4. 기본 가중치: 구조 35% + 경계 25% + 컬러 25% + 음영 15% (합 100%). `composite >=99.00`, `structure >=98.50`, `edges >=98.00`, `color >=99.00`, `light_shadow >=98.50`을 **동시에 통과**해야 `PASS_99_CANDIDATE`로 표시한다. 지표 값은 편집 가능한 가설이며 파일/렌더 버전과 함께 고정한다.
5. 높은 정량 점수도 최종 인증이 아니다. **시각 QA로 clipping, glyph overflow, 표/차트 누락, 레이어 편집 및 16:9 UX**를 확인한 뒤 별도의 `DESIGN_QA_PASS`를 기록한다. `sourceCheck=unavailable`이면 자동으로 `UNVERIFIED` 처리.
6. 각 페이지마다 원본·시안·50% 오버레이·차이 히트맵·점수 JSON·마스크 JSON·브라우저/OS/렌더러/DPI/폰트 버전·검토자를 보존한다. **합격 실패 모두 기록**.

```bash
python tools/visual_fidelity_score.py \
  --reference evidence/ubs-2025/p03/reference.png \
  --candidate evidence/ubs-2025/p03/docut-source-ratio.png \
  --mask evidence/ubs-2025/p03/text-regions.json \
  --reference-id UBS-GWR-2025-p03 \
  --output-dir evidence/ubs-2025/p03/audit
```

> **현재 실측 상태: UBS 2025 0/6, UBS 2026 0/6, 전체 20종 0/120.** 합격 점수를 꾸며내지 않는다. 점수기 자체의 합성 테스트 통과는 공식 보고서 유사도 통과와 무관.

## 5. 구현 Phase / 증거 기반 게이트

| Phase | 개발 범위 | 종료 기준 |
|---|---|---|

## 7. 원본 접근성·저작권·보안

원본 PDF를 보고 디자인 구조를 분석하는 것과, 로고·사진·독창적 일러스트·전체 페이지를 사실상 동일하게 내장해 배포하는 것은 다르다. 사용자에게는 원본 링크와 분석 요약을 제공하고, 기본 배포 템플릿은 독립적인 편집 가능한 벡터·데이터로 재구성한다. 원본 디자인에 대한 99% 시각 정밀복원은 **내부 비교 및 사용 권리 확보**를 전제로 하며, 라이선스가 허용하지 않으면 비슷한 기능을 가진 독립 디자인을 제공한다. 제3자 이미지나 상표를 DoCut 데이터에 무단 동봉하지 않는다.

문서 저장 및 CI: GitHub Actions 자동 실행 없음, EXE·APK·ZIP 생성 없음. 개발 후 일괄 테스트와 최소 커밋. Vercel 배포는 검증 완료 버전만 승격하고 실제 URL 응답 버전 재조회.
