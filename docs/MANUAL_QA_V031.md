# ⚠️ 수기 검증 필요 — Windows·Android

운영 화면의 버전 **STUDIO 0.31.0**을 확인한 뒤 테스트하세요.

1. 상단 페이지 띠에서 1→마지막 페이지→다른 주제를 선택합니다. 선택 위치가 첫 페이지로 되돌아가지 않아야 합니다. 썸네일 전환과 페이지 순서 드래그/Alt+방향키도 확인합니다.
2. 구성·속성·타임라인의 `⠿` 손잡이를 드래그합니다. 자유 배치, 크기 조절, 왼쪽/오른쪽/아래 도킹, 새로고침 후 위치 복원과 `배치 초기화`를 확인합니다. 화면 가장자리 드롭은 도킹, Alt를 누른 드래그는 자유 배치입니다.
3. `박스 구성·추출`에서 2·3·4개 / 가로·세로·2×2를 선택하고 새 페이지를 만듭니다. 소제목·본문·그림이 별도 객체인지 확인합니다. 공간 부족 메시지가 나오면 세로 비율 또는 그림 없는 구조를 선택합니다.
4. HTML 레퍼런스 파일을 선택해 구조·역할을 검토합니다. 내용 복사 체크 여부를 바꿔 본문과 이미지가 의도한 방식으로 들어오는지 확인합니다. 이미지 레퍼런스는 추정 박스에 누락·오분류가 있을 수 있으므로 추가 드래그와 역할 수정을 거칩니다.
5. 캔버스 객체를 우클릭합니다. DoCut 도구창이 나와야 합니다. 텍스트 더블클릭→일부 글자 선택→우클릭→글꼴/크기를 바꿔 선택 부분만 달라지는지 확인합니다. 애니메이션 버튼으로 실제 효과 창을 열고 적용·Undo를 확인합니다. Shift+우클릭은 브라우저 메뉴를 엽니다.
6. 두 개 이상 시트가 있는 XLSX 사본을 연결합니다. 워크시트와 A1:B4 같은 범위를 선택해 원본 숫자를 대조합니다. 차트 우클릭→연결 수정→다른 시트→검토/적용 시 같은 차트가 갱신되고 중복 생성되지 않아야 합니다.
7. 프로젝트 JSON 저장/재열기와 독립 HTML 출력을 확인합니다. 원자료·부분 글꼴·계층 구조는 유지되고 편집용 패널·우클릭 도구창은 결과 보고서에 없어야 합니다.

문제 보고 형식: 버전 / 기기·브라우저 / 조작 순서 / 기대 결과 / 실제 결과.
